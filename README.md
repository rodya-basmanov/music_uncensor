# 🎧 VK Music Uncensor

> Telegram-бот: превращает плейлисты ВКонтакте (а также **Яндекс.Музыки** и
> **Spotify** — через перенос в ВК) в треки: точные версии из VK или
> **незацензуренные** на YouTube/SoundCloud, с обложками и кэшем.

## 💡 Зачем это нужно

ВКонтакте **цензурит музыку**: треки с матом и «взрослым» содержанием
помечаются explicit и **блюрятся** — обложка размыта, а иногда трек вообще
недоступен. Собрать из такого плейлиста нормальную коллекцию для офлайн-прослушивания
или перенести её в Telegram неудобно: приходится вручную искать каждый трек, версию
без цензуры и подходящую обложку.

Этот бот решает три задачи:

1. **Uncensored-версии.** По плейлисту ВК находит трек на **YouTube/SoundCloud**
   — часто там лежит оригинал без цензуры (а для мешапов/редких версий — именно
   SoundCloud).
2. **Точные версии из VK.** Если нужна ровно та версия, что в плейлисте (например,
   live-запись), качает её **напрямую из VK** — с обложкой из VK.
3. **Перенос в Telegram.** Всё складывает в ваш **приватный канал**: треками с
   правильными названиями (`performer`/`title`), **обложками** и кэшем, чтобы не
   качать заново.

Проще говоря: кинул ссылку на плейлист ВК — получил коллекцию треков в Telegram,
сам выбираешь источник и версию, с обложками и без цензуры.

При этом не обязательно ограничиваться ВК: плейлисты из **Яндекс.Музыки и Spotify**
переносятся в ВК за пару кликов (приложение «Перенос музыки»), после чего бот
обрабатывает их как обычный VK-плейлист. Подробнее — в разделе
[«Плейлисты из Яндекс.Музыки и Spotify»](#-плейлисты-из-яндексмузыки-и-spotify).

## ✨ Возможности

| Возможность | Описание |
|------------|-----------|
| 🎧 **Яндекс.Музыка / Spotify** | Их плейлисты переносятся в ВК приложением «Перенос музыки» → VK-плейлист → бот |
| 🔗 **Входные ссылки** | Плейлист ВК, одиночный трек ВК, ссылка YouTube — бот сам определяет тип |
| ⬇️ **VK-загрузка** | Треки из VK качаются напрямую (точная версия из плейлиста) |
| ▶️ **YouTube / ☁️ SoundCloud** | Поиск и скачивание через yt-dlp (uncensored, мешапы) |
| 🎛 **Пикер результатов** | Вкладки-фильтры `🔀 Все / ▶️ YouTube / ☁️ SoundCloud / 🇻🇰 VK` + пагинация |
| 🧩 **Режимы VK-плейлиста** | Спросить: искать оригиналы / всё из VK / выбирать каждый трек |
| 🆓 **Свободный ввод** | Можно без тире (`saluki огней`, мешапы) — ищем как есть |
| 🔁 **Другой вариант** | Перекачать трек, выбрав другой источник, не выходя из поиска |
| 🖼 **Обложки** | Из VK-плейлиста (приоритет), иначе — родная обложка источника |
| 🏷 **Реальные названия** | В Telegram уходит `performer/title` из источника |
| 📡 **Живой статус** | Одно самообновляемое сообщение с прогресс-баром |
| ⚡ **Параллельно** | Пул воркеров + троттлинг отправки (защита от FloodWait) |
| 💾 **Кэш** | SHA256 → повторная отправка через `file_id` без скачивания |
| 🎨 **Rich-интерфейс** | Меню, справка, пикер, живой статус и статистика — rich-сообщения + цветные кнопки |
| 🐳 **Docker** | Запуск одной командой `docker compose up -d` (ffmpeg внутри образа) |

## 🚀 Быстрый старт

```bash
git clone https://github.com/rodya-basmanov/music_uncensor.git
cd music_uncensor

pip install -r requirements.txt

cp .env.example .env      # затем заполните .env
python bot/main.py
```

> **ffmpeg** нужен для конвертации в MP3 — если системного нет, `imageio-ffmpeg` подставит свой.
> Для YouTube в РФ нужен прокси (см. `YTDLP_PROXY`).

## 🐳 Docker

Запуск одной командой (ffmpeg и все зависимости — внутри образа):

```bash
cp .env.example .env          # заполните BOT_TOKEN, VK_TOKEN, прокси
docker compose up -d --build
docker compose logs -f        # логи
```

Данные (кэш, `users.json`, `stats.json`) лежат в `./data` (том, переживает перезапуск).
Обновление: `git pull && docker compose up -d --build`. Остановить: `docker compose down`.

## ⚙️ Конфигурация (`.env`)

| Переменная | По умолчанию | Описание |
|-----------|-------------|----------|
| `BOT_TOKEN` | — | Токен Telegram-бота (обязательно) |
| `TELEGRAM_PROXY_URL` | — | SOCKS5/HTTP прокси для Telegram API (**не MTProto**) |
| `VK_TOKEN` | — | User access token VK (плейлисты/треки по ссылке) |
| `VK_PLAYLIST_MODE` | `ask` | `ask` / `uncensored` / `vk` — поведение для VK-плейлистов |
| `SOURCE_ORDER` | `youtube,soundcloud` | Порядок источников поиска |
| `YTDLP_PROXY` | = `TELEGRAM_PROXY_URL` | Прокси для yt-dlp (YouTube) |
| `DATA_DIR` | `./data` | Папка данных (users.json) |
| `MAX_PLAYLIST_SIZE` | `500` | Максимум треков в плейлисте |
| `CONCURRENCY` | `3` | Сколько треков обрабатывать параллельно (1 — по порядку) |
| `SEND_INTERVAL` | `3` | Пауза между отправками аудио, сек (анти-FloodWait) |
| `RATE_LIMIT_SEARCH_SEC` | `2` | Задержка между треками при поиске |
| `CACHE_DIR` | `./data/cache` | Папка кэша |
| `CACHE_TTL_DAYS` | `7` | Срок жизни кэша (дней) |
| `MAX_CACHE_SIZE_GB` | `20` | Макс. размер кэша (ГБ) |
| `LOG_LEVEL` | `INFO` | Уровень логирования |
| `SENTRY_DSN` | — | Sentry (опционально) |
| `WEBHOOK_MODE` / `WEBHOOK_*` | — | Альтернатива polling |

## 🔑 VK-токен

Нужен, чтобы бот читал плейлисты/треки по ссылке.

1. Откройте <https://vkhost.github.io/>
2. Выберите приложение **«Kate Mobile»** (есть доступ к аудио) → **Получить** → **Разрешить**
3. Из адресной строки `https://oauth.vk.com/blank.html#access_token=XXXX&expires_in=...`
   скопируйте `XXXX`
4. Вставьте в `.env`: `VK_TOKEN=XXXX` и перезапустите бота

> Токен даёт доступ к аккаунту — не коммитьте его и не передавайте.
> Если `audio.get` возвращает пусто — попробуйте другое приложение в vkhost (VK Me / VK Admin).

## 📖 Использование

**1. Создайте приватный канал** и добавьте бота администратором.

**2. Привяжите канал** — отправьте в канале `@ваш_бот /link`.
Из ЛС: `/link -100XXXXXXXXXX`.

**3. Отправьте боту в личку:**

- 🔗 **Ссылку на плейлист ВК** (в т.ч. перенесённый из Яндекс.Музыки/Spotify) — бот спросит режим:
  - 🔍 **Искать оригиналы (uncensored)** — YouTube→SoundCloud, VK только как фолбэк;
  - ⬇️ **Всё из VK** — точные версии;
  - 🎛 **Выбирать каждый** — по каждому треку пикер.
- 📋 **Список треков** (текст или `.txt`): `Исполнитель - Название`, по одному на строку.
- 🎵 **Один запрос** — покажет результаты с вкладками источников.
- 🔗 **Одиночный трек ВК** или **YouTube** — скачает именно его.

> 💡 Нужен плейлист из **Яндекс.Музыки или Spotify**? Сначала перенесите его в ВК —
> см. раздел ниже.

### 🎧 Плейлисты из Яндекс.Музыки и Spotify

Бот работает с плейлистами ВК, а Яндекс.Музыку и Spotify можно перенести в ВК за
пару кликов — прямо из ВК, без сторонних сервисов:

1. Откройте приложение ВК **«Перенос музыки»** — <https://vk.ru/app8116845>
2. Вставьте ссылку на плейлист из **Яндекс.Музыки** или **Spotify**
3. Приложение создаст ваш плейлист в ВК (пара секунд)
4. Пришлите боту ссылку на этот **VK-плейлист** — он всё скачает

Для остальных сервисов — аналогично, если их поддерживает приложение.

| Команда | Описание |
|---------|----------|
| `/start` | Меню и инструкция |
| `/help` | Справка |
| `/link` | Привязать канал (в канале или `/link -100XXX`) |

| `/stats` | Статистика |
| `/cancel` | Отменить текущую задачу |

## 🔎 Как работает

```
Трек из VK-плейлиста ("Artist - Title")
        │
        ├─ режим «Всё из VK» ────────► скачать напрямую с VK (+ обложка VK)
        │
        └─ режим «uncensored» ───────► поиск YouTube → SoundCloud
                                        │  yt-dlp: скачать, обложка источника
                                        └─ не найдено → фолбэк: скачать с VK
Обложка: VK (приоритет) → обложка источника
```

Свободный запрос без тире (мешап) ищется как есть; SoundCloud ставится вперёд
для мешапов (`flip`/`remix`/…). Несколько треков качаются **параллельно**
(`CONCURRENCY`), отправка в канал **сериализована** с паузой `SEND_INTERVAL`.

Плейлисты из **Яндекс.Музыки/Spotify** сначала переносятся в ВК приложением
«Перенос музыки», затем обрабатываются как обычный VK-плейлист.

## 🔧 Устранение проблем

| Проблема | Решение |
|---------|---------|
| Бот не запускается | Проверьте `BOT_TOKEN` в `.env` |
| Telegram недоступен | Нужен SOCKS5/HTTP прокси в `TELEGRAM_PROXY_URL` (не MTProto) |
| YouTube не качается (403) | Обновите `yt-dlp` и задайте `YTDLP_PROXY` |
| Канал не привязывается | Бот должен быть админом канала |
| FloodWait при отправке | Увеличьте `SEND_INTERVAL` |
| Нужен плейлист из Яндекс.Музыки/Spotify | Перенесите его в ВК приложением <https://vk.ru/app8116845> и пришлите VK-ссылку |
| Треки не находятся | Попробуйте свободный запрос/пикер с вкладками источников |

CI (GitHub Actions) прогоняет их на Python 3.11 и 3.12 при каждом push/PR.

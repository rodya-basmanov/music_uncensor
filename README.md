# 🎧 VK Music Uncensor

> Telegram-бот для экспорта плейлистов из ВКонтакте с автоматическим поиском **незацензуренных** версий треков.

![Python](https://img.shields.io/badge/Python-3.11+-blue?logo=python)
![aiogram](https://img.shields.io/badge/aiogram-3.x-purple)
![License](https://img.shields.io/badge/License-MIT-green)

## ✨ Возможности

| Возможность | Описание |
|------------|-----------|
| 🎵 **SoundCloud** | Основной источник — поиск uncensored версий через yt-dlp (работает в РФ без VPN) |
| 🔄 **mp3party** | Fallback-источник если SoundCloud не нашёл трек |
| 🧠 **Умный выбор** | Приоритет: трек от артиста → не-ремикс → ближайший по длительности |
| 🚫 **Фильтрация** | Автоматически исключает slowed, reverb, sped up, remix |
| 📝 **Оригинальные названия** | В Telegram отправляются с `feat.`, `prod. by`, для поиска — очищенные |
| 💾 **Кэширование** | SHA256-хеш → повторная отправка через `file_id` без скачивания |
| 🎯 **Fuzzy-матчинг** | `rapidfuzz` для неточного совпадения треков |
| ⏱ **Проверка длительности** | Треки с неподходящей длиной отбрасываются |

## 🚀 Быстрый старт

### 1. Установка

```bash
# Клонируем репозиторий
git clone https://github.com/your-repo/vk-music-uncensor.git
cd vk-music-uncensor

# Устанавливаем зависимости
pip install -r requirements.txt

# Устанавливаем playwright (для fallback с mp3party)
playwright install chromium
```

> **ffmpeg** нужен для конвертации в MP3. Если не установлен системно, `imageio-ffmpeg` поставит автоматически.

### 2. Настройка

```bash
cp .env.example .env
```

Отредактируйте `.env`:

```env
# Обязательно
BOT_TOKEN=your_telegram_bot_token_from_BotFather

# Опционально
TELEGRAM_PROXY_URL=socks5://user:pass@host:port  # Прокси для Telegram API
FUZZY_THRESHOLD=85  # Порог fuzzy-матчинга (0-100)
LOG_LEVEL=INFO
```

### 3. Запуск

```bash
python bot/main.py
```

## 📖 Использование

### Шаг 1: Создайте Telegram-канал

1. Создайте **приватный канал** в Telegram
2. Добавьте бота как **администратора**
3. Выдайте право **«Отправка сообщений»**

### Шаг 2: Привяжите канал

**Способ А** (в канале):
```
В канале отправьте: /link
```

Бот ответит:
```
✅ Chat ID этого канала: -1001234567890
Канал привязан и установлен по умолчанию.
```

**Способ Б** (в ЛС):
```
/link -1001234567890
```

### Шаг 3: Экспортируйте плейлист из VK

1. Откройте плейлист ВКонтакте в браузере
2. Нажмите **F12** → вкладка **Console**
3. Вставьте содержимое [`script.js`](script.js) и нажмите Enter
4. Скрипт прокрутит плейлист и скачает `.txt` файл

### Шаг 4: Отправьте боту

**Вариант А:** отправьте полученный `.txt` файл боту в ЛС

**Вариант Б:** скопируйте текст:
```
-1001234567890
J.ROUH feat. SALUKI - SALUT
Макс Корж - Неважно (Acoustic)
масло черного тмина - тысячу раз спокойной ночи
```

Первая строка — `chat_id` канала, далее треки в формате `Артист - Название`.

## 🔎 Как работает поиск

```
┌─────────────────────────────────────────────────────────────┐
│                    Трек из VK                                │
│         "J.ROUH feat. SALUKI - SALUT [220 сек]"             │
└─────────────────────────────────────────────────────────────┘
                              │
                              ▼
                 ┌────────────────────────────┐
                 │   Очистка для поиска:      │
                 │   artist: "J.ROUH"         │
                 │   title: "SALUT"           │
                 └────────────────────────────┘
                              │
          ┌───────────────────┴───────────────────┐
          ▼                                       ▼
      SoundCloud                              mp3party
      scsearch5                              search API
  "J.ROUH SALUT"                             "J.ROUH SALUT"
          │                                       │
     5 результатов                         fuzzy match
          │                                       │
          ▼                                       ▼
   Лучший кандидат:                      Fallback если
   1. от артиста                          SoundCloud не нашёл
   2. не remix
   3. по duration
          │
          ▼
┌─────────────────────────────────────────────────────────────┐
│                   Результат                                   │
│   ✅ Отправлено в канал / ⚠️ Не найдено                       │
└─────────────────────────────────────────────────────────────┘
```

**Оригинальные названия** (с `feat.`, `prod. by`) сохраняются для отображения в Telegram. Очистка применяется **только** к поисковым запросам.

## ⚙️ Конфигурация

| Переменная | По умолчанию | Описание |
|-----------|-------------|----------|
| `BOT_TOKEN` | — | Токен Telegram-бота (обязательно) |
| `TELEGRAM_PROXY_URL` | — | SOCKS5 прокси для Telegram API |
| `FUZZY_THRESHOLD` | 85 | Порог fuzzy-матчинга (0–100) |
| `MAX_PLAYLIST_SIZE` | 100 | Максимум треков в плейлисте |
| `CACHE_DIR` | `./data/cache` | Папка кэша |
| `CACHE_TTL_DAYS` | 7 | Срок жизни кэша (дней) |
| `MAX_CACHE_SIZE_GB` | 20 | Макс. размер кэша (ГБ) |
| `RATE_LIMIT_SEARCH_SEC` | 2 | Задержка между поисками (сек) |
| `RATE_LIMIT_DOWNLOAD_SEC` | 2 | Задержка между скачиваниями (сек) |
| `LOG_LEVEL` | INFO | Уровень логирования |

```

├── bot/                        # Telegram-бот (aiogram 3.x)

│   │   └── mp3party.py        # mp3party.net (fallback)
│   ├── matcher.py             # Fuzzy-матчинг (rapidfuzz)
│   ├── downloader.py          # Скачивание с retry
│   └── cache_manager.py       # Кэш: hash → файл + telegram file_id
```

## 🔧 Устранение проблем

| Проблема | Решение |
|---------|---------|
| Бот не запускается | Проверьте `BOT_TOKEN` в `.env` |
| Канал не привязывается | Убедитесь что бот — админ канала |
| Треки не находятся | Попробуйте изменить название (уберите feat.) |
| Медленная работа | Уберите прокси или увеличьте `RATE_LIMIT` |
